# 🌱 허브 (Herb)

텃밭·화분에서 작물을 처음 키우는 초보자도, AI의 도움을 받아 쉽고 간편하게 작물을 키울 수 있도록 돕는 웹 서비스입니다.

## 문제정의

농수산 분야의 생산성과 접근성을 높이려면, 재배 경험이 전혀 없는 사람도 쉽게 시작할 수 있어야 합니다. 하지만 초보자는 다음과 같은 어려움을 겪습니다.

- 작물마다 물주기·비료·지지대 설치 시점이 달라 언제 무엇을 해야 할지 모른다
- 식물 상태(병충해, 영양 부족 등)를 스스로 진단하기 어렵다
- 텃밭(노지)은 날씨 변화에 관리 일정이 크게 좌우되지만, 이를 실시간으로 반영하기 어렵다

**허브**는 작물명과 재배 환경만 입력하면 AI가 심기부터 수확까지의 맞춤 가이드라인을 자동 생성하고, 사진·날씨 데이터를 바탕으로 그 가이드라인을 실시간으로 조정해주는 서비스입니다.

## 주요 기능

- 회원가입 / 로그인 (비밀번호 해시 저장), 이메일 변경·비밀번호 변경·계정 삭제 (모두 비밀번호 재확인 후 처리)
- 화분 / 텃밭 재배 환경 선택 후 각각의 홈 화면 이용
- 작물명 · 크기 입력만으로 AI가 심기부터 수확까지의 단계별 가이드라인 자동 생성 (토마토·가지·고추·상추·오이·깻잎·파·애호박·감자·당근·고구마·마늘·바질 등 13종 + 자유 입력), 각 단계 완료 체크 및 진행률 표시
- **화분**: 식물 사진을 올리면 AI가 생육 상태를 정밀검사하고 가이드라인 조정
- **텃밭**: 위치를 입력하면 AI가 실시간 날씨(웹 검색)를 반영해 가이드라인 조정
- **비료 추천**: 잎·줄기 / 열매채소 / 알뿌리 / 척박·특수 4개 그룹별 맞춤 비료 정보를 제공하고, 그룹에 없는 작물은 AI가 그 자리에서 생성
- **현재 상태 메모**: 화분·텃밭마다 한 줄 메모(예: "꽃이 피기 시작함")를 남길 수 있음
- **날씨·긴급 위기 알림**: 텃밭 위치 기준으로 하루 한 번 폭염·한파·태풍 등 위험을 확인해 홈 화면과 브라우저 알림으로 안내 (같은 지역 텃밭은 하나의 알림으로 묶어서 표시)
- **수확 후기 분석**: 수확 후 남긴 후기를 AI가 문장 단위로 나눠 각 문장이 말하는 포인트에 맞는 작물을 하나씩 추천하고, 후기 전체를 종합한 다음 작물도 함께 추천 (추천은 항상 앱에 실제 등록된 작물 중에서만 이뤄지도록 제한)
- 화분 / 텃밭 이용자 전용 커뮤니티 대화방 (매일 자동 초기화)
- AI(화분봇 / 텃밭봇)와의 1:1 상담 채팅 (대화 맥락 유지, 매일 자동 초기화, 첫 대화 시 추천 질문 버튼 제공)
- **다국어 지원**: 한국어 · English · 日本語 · 中文 · Français 5개 언어로 전체 UI와 AI 응답을 전환

## 아키텍처

```
사용자(브라우저)
     │
     ▼
Streamlit 앱 (app.py)
     │
     ├── auth.py       — 회원가입/로그인/이메일·비밀번호 변경/계정 삭제, PBKDF2-SHA256 비밀번호 해시 저장
     ├── pots.py        — 화분 데이터 CRUD, 작물별 기본(사전 정의) 가이드
     ├── gardens.py     — 텃밭 데이터 CRUD (pots.py와 동일 구조), 위치·날씨 위기 캐시
     ├── chat.py        — 커뮤니티/1:1 채팅 저장 및 일일 자동 초기화
     ├── care.py        — 작물별 추천 흙 / 천연비료 정보 (사전 정의)
     ├── fertilizer.py  — 그룹별(잎줄기/열매채소/알뿌리/척박) 비료 추천 + AI 즉석 생성 캐싱
     └── ai.py          — Anthropic Claude API 연동 (재시도 로직 포함)
            │
            ▼
     Claude API (claude-opus-5)
     ├─ 재배 가이드라인 생성 (구조화 출력)
     ├─ 사진 기반 생육 정밀검사 (Vision)
     ├─ 위치 기반 날씨 정밀검사 · 긴급 위기(폭염·한파 등) 확인 (Web Search 도구)
     ├─ 그룹에 없는 작물의 비료 추천 즉석 생성
     └─ 커뮤니티/1:1 AI 챗봇 응답
```

데이터는 로컬 JSON 파일(`users.json`, `pots.json`, `gardens.json`, `chat.json`)에 저장됩니다.

## 사용 스택

- **Python 3**
- **Streamlit** — 프론트엔드 + 백엔드
- **Anthropic Claude API** (`claude-opus-5`) — 재배 가이드 생성, 사진 진단(Vision), 웹 검색 기반 날씨 진단, AI 챗봇
- **JSON 파일 기반 저장소** (별도 DB 서버 없이 동작)

## 실행 방법

```bash
git clone https://github.com/Jangjorim1116/smartfarm-app.git
cd smartfarm-app
pip install -r requirements.txt
```

`.streamlit/secrets.toml` 파일을 만들고 아래 내용을 입력합니다. (선택 사항 — 없어도 AI 기능은 사전 정의된 기본 가이드로 자동 대체되어 앱이 정상 동작합니다.)

```bash

```

## AI 사용 내역

- **모델**: Anthropic `claude-opus-5`
- **재배 가이드라인 생성**: 사용자가 입력한 작물명·재배 환경(화분/텃밭) 크기를 바탕으로 심기부터 수확까지의 단계별 일정을 구조화된 JSON(`output_config.format`)으로 생성
- **사진 기반 정밀검사 (화분)**: 업로드된 식물 사진을 Claude Vision으로 분석해 생육 상태·병충해를 진단하고, 그 결과를 반영해 가이드라인을 재조정
- **위치 기반 날씨 정밀검사 (텃밭)**: Claude의 `web_search` 도구로 입력한 지역의 실시간 날씨(강수·기온 등)를 검색하고, 이를 반영해 관리 일정을 재조정
- **날씨·긴급 위기 확인 (텃밭)**: 등록된 위치를 기준으로 하루 한 번 `web_search`로 폭염·한파·태풍 등 특보를 확인하고, 위험할 때만 경고 메시지를 생성
- **비료 추천 생성**: 미리 정의한 4개 그룹(잎·줄기/열매채소/알뿌리/척박·특수)에 없는 작물을 심으면, 그 자리에서 AI가 같은 형식(특징·재배 팁·밑거름·웃거름·주의사항)으로 비료 추천을 생성하고 세션 동안 캐싱
- **수확 후기 기반 다음 작물 추천**: 후기를 문장 단위로 나눠 문장마다 별도로 작물을 추천하고, 후기 전체를 종합한 추천도 함께 생성. 두 경우 모두 `crop` 필드를 JSON 스키마의 `enum`으로 앱에 실제 등록된 작물 목록에만 묶어(constrain), 앱에 없는 작물이 추천되지 않도록 함
- **AI 챗봇 (화분봇 / 텃밭봇)**: 재배 환경별로 특화된 시스템 프롬프트를 사용해 답변하며, 1:1 상담은 전체 대화 맥락을 유지한 채 이어짐
- API 키가 없거나 호출이 실패하는 경우, 사전 정의된 규칙 기반 가이드로 자동 대체되어 서비스가 중단되지 않음
- Anthropic 서버가 일시적으로 과부하(529)일 때를 대비해 모든 API 호출에 지수 백오프 재시도(최대 3회) 적용
